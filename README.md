# Myリペア

暮らしの修理項目を管理する、個人向けの静的 Web アプリです。  
「どの修理を誰に頼めるか」を記録し、修理記録ページへの導線もまとめて管理できます。

## 主な機能

- 修理項目の一覧表示（カテゴリ付き）
- 各項目に対して「自分で / 身近な人 / 業者」を選択
- 選択内容を `localStorage` に保存し、離脱時などにCookieセッション単位でAPIへ同期
- 上部パネルに進捗表示
  - 登録済み割合（薄い色）
  - 自分でできる割合（濃い色）
- 「自分で」を選んだ項目カードを濃い色で強調表示
- 修理方法リンクの表示（カテゴリ展開あり）
- 外部の修理記録（Myエコライフ記録）との連携
- ライト / ダークテーマ切り替え

## 使い方

1. `index.html` をブラウザで開く
2. 各修理項目で「自分で / 身近な人 / 業者」を選ぶ
3. 進捗パネルで割合を確認する
4. 必要に応じて「修理方法」や「修理済 / 新規記録」リンクを開く

## データ保存

このアプリは通常、ブラウザの `localStorage` に保存します。ページ離脱時などに、Cookieセッションに対応するサーバーへ同期します。Cookieを削除すると、サーバー側の保存データを呼び出せなくなる場合があります。

- 修理可能性の保存キー: `myrepair-owners`
- 外部連携データの参照キー: `homeenergycodes.savedInput`
- テーマ保存キー: `myrepair-theme`

## ファイル構成

- `index.html`: 画面構造
- `styles.css`: スタイル定義（色分け、レイアウト、レスポンシブ）
- `app.js`: データ・描画・保存処理
- `設計/about.md`: 設計メモ

## カスタマイズのヒント

- 修理項目を増減する場合は `app.js` の `repairs` 配列を編集
- 色味を変更する場合は `styles.css` の CSS 変数を調整
  - `--accent`: 基本アクセント
  - `--accent-deep`: 自分でできる項目の濃色
  - `--accent-soft`: 薄色（背景や進捗下層）

## 備考
